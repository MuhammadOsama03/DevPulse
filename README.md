# DevPulse

A developer-focused application health and API monitoring dashboard.

> **Status: early work in progress.** This repository is intentionally incomplete.

## Planned features

- Service health overview and status indicators
- API response time and error-rate charts
- Historical monitoring events
- Alerts and notification settings (later)
- Persistent metrics storage (later)

## Planned stack

Next.js + TypeScript frontend, Node.js + Express API, and PostgreSQL in a later phase.
